# Minimal ASYSMA v1 Package Example

This is a textual package blueprint for the first executable profile.

```text
ASYSMA header v1
manifest
integrity descriptor
x86-64 native bootstrap
host-profile contract
ASYSMA policy
SecureJDK 28 Java entry
CMD-origin icon metadata
resources
```

## Launch contract

```text
1. OS native loader accepts the platform representation.
2. Native bootstrap validates its entry context.
3. Direct adapter establishes the OS boundary.
4. Host profile records OS/version/memory/storage observations.
5. Integrity is verified.
6. ASYSMA policy evaluates the profile.
7. SecureJDK 28 starts.
8. Java application starts.
```

A future binary fixture must use the concrete header encoding and cryptographic profile approved for that release. This document is not itself an executable.
