# Icon Source and Provenance

The original icon family for this program is the CMD icon set.

Source archive:

`/icons/cmd/cmd/cmd-icon-four-trimmed-transparent-v2.zip`

## Historical order

1. **CMD was first.**
2. The CMD icon set is the established launcher/program artwork.
3. **ASYSMA initially reuses the same icons** for `.asysma` executables.
4. Native packaging may convert formats without changing the source identity.

The initial ASYSMA release therefore intentionally presents the same visual identity as CMD. A later independent ASYSMA identity can be introduced only as a documented design revision.
