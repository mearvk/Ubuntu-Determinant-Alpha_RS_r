# Trillian Open Chat Upstream

## Upstream selected

**Project:** Dino
**Repository:** https://github.com/dino/dino
**License:** GPL-3.0
**Primary technology:** Vala / GTK

Dino is an open-source XMPP desktop messaging application. The upstream project documents support for encrypted messaging, group chats, file transfers, and calls. citeturn0search0

## Why Dino

The goal is a full-featured open chat foundation with a permissive-to-use open-source development workflow appropriate for a clearly attributed derivative project under the applicable GPL terms. It provides substantially more than a minimal chat demo.

## Attribution rule

This project must preserve the upstream copyright and license notices required by GPL-3.0 and must clearly distinguish upstream Dino material from project-specific modifications.

## Trillian distinction

The historical Cerulean Studios Trillian client is not being represented as open source. `/trillian` is a new project area using an open-source chat foundation for independent development and historical/UI inspiration.
