# 1 — Provenance and Purpose

This document establishes the first layer of the project record: what is being
built, why it exists, and where evidence comes from.

The Smaug subsystem is an experimental C/C++ decision and simulation framework.
Its vocabulary includes Castle, Overtine, Companion, Emerald, Smite, Firecaster,
Dream, Wanderer, Detail, Treasure, and protected administrative gates.

These names describe software models. They are not scientific claims about
intelligence, physical power, human worth, or authority.

## Evidence rule

Every consequential modeled transition should retain source, identity, sequence,
inputs, normalized evidence, decision, and review status where applicable.

## Source classes

- Player input: direct user request or observation.
- Overtine input: structured companion request or observation.
- System observation: operating-system or program state.
- Administrative record: explicitly authorized system operation.

No source becomes authoritative merely by supplying an input.
