# Wells Fargo CSS Archive

CSS destination for the captured Wells Fargo pages under `internet-sites/wellsfargo.com/`.

Page-specific files use the requested form:

`internet-sites/css/PAGENAME/doc.css`

The current GitHub/web connector can retrieve the captured HTML but cannot directly retrieve Wells Fargo `text/css` resources. The live homepage confirms that the site is publicly accessible; stylesheet byte retrieval must be performed from a networked capture environment before inserting the original CSS bytes.
