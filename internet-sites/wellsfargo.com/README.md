## Scope

This repository therefore stores a reference/manifest rather than a full third-party site clone.

## Intended use

Use this directory as the canonical external-site record for the project. If a specific Wells Fargo page is needed for research, documentation, compatibility testing, or a lawful archival purpose, add a narrowly scoped citation or locally authored analysis rather than copying the entire site.
