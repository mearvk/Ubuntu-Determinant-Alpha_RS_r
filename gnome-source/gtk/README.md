# GTK — Upstream README Record

GTK is a multi-platform toolkit for creating graphical user interfaces. It provides a complete widget set and is hosted by the GNOME project. GTK is released under the GNU LGPL 2.1 or later. Upstream build dependencies include a C11 compiler, Python 3, Meson, Ninja, GLib, GdkPixbuf, GObject-Introspection, Cairo, Pango, Epoxy, Graphene, and Xkb-common.
