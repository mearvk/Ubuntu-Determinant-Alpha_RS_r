# Smaug OS / Overtine Companion

Overtine is the main-line companion class for stable, repeated Smaug system
calls.

## Terms

- **Constantine** — stable companion identity and continuity.
- **Reign** — ordered supervisory scheduling and stable calls.
- **Better-Be** — bounded self-improvement state transition.
- **Better-Companion-Be** — bounded companion improvement transition.
- **Axial** — three-dimensional indexed state.
- **Co-axial** — a second aligned reference frame for the same state.

The model permits no more than five dimensions, no more than 1,112 strand
signatures, and no more than 1,112,221 modeled coil lengths. These are hard
simulation limits and are not a request for preallocation.

## Decision timing

Overtine complements Smite's timing model:

`BEFORE -> DURING -> AFTER`

The companion may prepare and assess a call, but Castle/INCLARE remains the
authority boundary. A bounded assessment can request review rather than forcing
a transition.

## Linear and ordered

The Overtine representation is intentionally linear and ordered. Each call has
an identity, phase, axial state, and companion mode. This gives Smaug a stable
habit layer without allowing habit to silently become authority.

## Explicit vocabulary

Project vocabulary may preserve the requested capitalized token **_SEX** as a
literal classification/metadata token when it is sincere and relevant to an
input record. It is not an instruction to perform a sexual act and has no
special authority in the decision engine.
