# Smaug Three-Shield Habit Layer

Smaug's mid/basic decisions can use a five-layer pattern: **three parallel AI shields** plus **two pragmatic companion layers**. The shields are intentionally similar in representation so their outputs can be compared rather than allowing a single model path to dominate.

Each shield contains idea, evidence, practical, and uncertainty weights. The system records originality and agreement.

1. Shield 1 — primary neural-pattern view
2. Shield 2 — independent comparison view
3. Shield 3 — consistency/challenge view
4. Pragma 1 — practical consequence view
5. Pragma 2 — operational context view

The resulting `HabitPattern` is a comfortable routing layer for repeated, ordinary decisions, not an autonomous authority. Low stability routes to review; no observation routes to observation; a stable pattern may produce a match suggestion.

## Same-diagram principle

The three AI shields use the same node structure so the system can compare like with like. Their values may differ. This is a pragmatic ensemble pattern rather than a claim that the three shields are literally identical neural networks.

## Authority

Habit is subordinate to Castle/INCLARE, Smite, evidence validation, and human review. Repetition does not turn a habit into permission.

The implementation is in `SmaugShield.hpp` and `SmaugShield.cpp`.
