git-temperature(1)
==================

NAME
----
git-temperature - Advisory scan for stale and recandle-worthy projects

SYNOPSIS
--------
[synopsis]
git temperature [<repo>] [--recandle] [--min-idle <days>]

DESCRIPTION
-----------
`git temperature` is a read-only advisory scan from the Ubuntu Determinant Git
method. It walks the repository's project subtrees, identifies projects that
were started and may since have been left alone, and reports which could still
be improved or "recandled" (revived).

Each project is placed in a thermal band by how long it has been idle
(`hot`, `warm`, `cool`, `cold`) and summarized by three learner strips on a
0..100 scale: quality and intention, relative importance, and total achievable
value (the improvement headroom over current quality, scaled by importance). A
cold or cool project that is important and improvable is flagged as a recandle
candidate.

The operation is advisory: it never stages, commits, pushes, or rewrites
anything, and its scores use observable project signals only, never author
identity or credentials. See the `TEMPERATURE.md` metadoc for the full model.

OPTIONS
-------
`--recandle`::
	Limit the listing to recandle candidates.

`--min-idle <days>`::
	Restrict the listing to projects idle at least `<days>` days. The
	repository totals still account for every scanned project.
